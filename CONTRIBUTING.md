# Katkıda bulunma

1. Bir issue açın veya küçük bir pull request hazırlayın.
2. `npm install && npm run check` çalıştırın.
3. Yeni işlevlere uygun testler ekleyin.
4. Üçüncü taraf medyaları, izinsiz sesleri, fontları veya telifli rehber metinlerini yüklemeyin.
5. Remotion'un lisansını MIT gibi göstermeyin. Bu deponun MIT lisansı yalnızca özgün kod ve belgelere uygulanır.
